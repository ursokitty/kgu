# 경기대학교 중어중문전공 학과 홈페이지

경기대학교 인문대학 중어중문전공 학과 홈페이지입니다. 2025 개편 교육과정과 세 갈래 이수 경로(단일트랙 · 융합트랙 · 마이크로디그리), 비교과 활동과 학생 혜택을 소개합니다.

## 페이지

| 파일 | 내용 |
|---|---|
| `index.html` | 대문: 하늘 배너와 붓글씨 `前进中文`, 학과 소개 영상, 공지 · 소식, 학년별 맞춤 안내, 1분 소개 스토리, 이수 경로, 융합트랙 이수체계도, 만족도, 비교과, 학생 혜택 |
| `about.html` | 학과소개: 학과 소개, 배우는 것, 교환학생, 교육목표, 학생 활동, 진로, 위치 및 연락처 |

## 폴더 구성

```
├── index.html          대문
├── about.html          학과소개
├── assets/
│   ├── style.css       공통 스타일 (라이트 / 다크 모드)
│   ├── app.js          공통 스크립트 (한 · 中 · EN 번역 사전, 모션, 검색)
│   └── kgu-logo.png    경기대학교 로고
├── data/               내용의 근거 자료 (의뢰서, 교육과정표, 트랙 · 비교과 정리, 그림 1~3)
└── CLAUDE.md           제작 지침 (Claude 작업 규칙)
```

## 주요 기능

- **한 / 中 / EN 전환**: 모든 문구가 `assets/app.js`의 번역 사전으로 바뀝니다. 한국어 화면에서는 제목 아래 작은 중국어가 함께 보입니다.
- **라이트 / 다크 모드**: 다크 모드에서는 대문 밤하늘에 홍등이 떠오릅니다.
- **대문 하늘**: WebGL로 그린 구름이 흐르고, 하늘이 경기대 파랑과 노을빛 사이를 오갑니다.
- **붓글씨**: `前进中文`이 획순대로 써지고 낙관이 찍힙니다. 누르면 다시 씁니다.
- **통합검색**: 배너 검색창이나 키보드 `/` 또는 `Ctrl + K`로 엽니다.
- **학년별 맞춤 안내**: 고등학생 · 1학년 · 재학생 · 4학년을 고르면 필요한 메뉴만 보여 줍니다.
- **1분 소개 스토리**: 인스타 스토리처럼 자동으로 넘어갑니다. 누르고 있으면 멈추고, 옆으로 밀면 넘어갑니다.
- **이수체계도**: 스크롤하면 학기별 과목이 켜지고 학점이 쌓입니다.
- **홍바오**: 학생 혜택에서 빨간 봉투를 위로 밀면 장학금 카드가 나옵니다.
- **BARUN 일정**: 오늘 날짜를 기준으로 진행 중 · 지난 일정을 자동으로 나눕니다.

## GitHub Pages로 공개하기

1. 이 폴더의 파일을 저장소 맨 위(루트)에 올립니다. `index.html`이 루트에 있어야 합니다.
2. 저장소의 **Settings → Pages**로 갑니다.
3. **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/`에서 열립니다.

> 학과 소개 영상(YouTube)과 지도는 파일을 더블클릭해 열면(`file://`) 막힐 수 있습니다. GitHub Pages나 VS Code의 Live Server처럼 웹 주소로 열면 정상적으로 재생됩니다.

## 내용 수정

- **문구**: `assets/app.js`의 `I18N` 사전에서 고칩니다 (ko · zh · en).
- **공지사항**: `assets/app.js`의 `NOTICES` 배열에 추가합니다.
  ```js
  var NOTICES = [
    { title: { ko: '공지 제목', zh: '公告标题', en: 'Notice title' }, date: '2026-11-10', pin: true }
  ];
  ```
- **BARUN 일정**: `assets/app.js`의 `PROGRAMS` 배열에서 고칩니다.
- **사실 근거**: 모든 내용은 `data/` 폴더 자료에 근거합니다. 자료에 없는 내용은 "학과사무실 확인 필요"로 표시합니다.
